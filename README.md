# Deskbay

Find a Mumbai cafe you can actually work from. Deskbay scores 30 cafes across Bandra and
South Bombay on wifi, power, noise, seating and five other factors, with every finding cited,
on an interactive 3D map (MapLibre GL + OpenFreeMap).

## Stack

- Next.js 16 (App Router)
- Tailwind CSS v4
- MapLibre GL JS for the 3D map (no API key required)

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run start
```
